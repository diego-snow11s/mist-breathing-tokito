# 🌫️ Mist Breathing — Tokito Muichiro

> A clean dark Hydra Launcher theme inspired by Demon Slayer's Mist Hashira

---

## ✨ About
- **Style**: Minimal dark · icy blue glow · translucent interface
- **Background**: Muichiro Tokito in combat
- **Built for**: Hydra Launcher v4.2.0+

---

## 📦 Installation

1. Open Hydra → **Settings → Appearance**
2. Click **Create** → name it `Mist Breathing`
3. Open the editor → replace everything with the code from `theme.css`
4. **Save** → **Enable Theme** ✅

### Achievement Sound (Optional)
1. Place your sound file in the theme folder
2. Rename it to: `achievement.mp3` (supports `.mp3` `.wav` `.ogg` `.m4a`)
3. In the theme editor → click **Select** → pick the file
4. Save — done! 🎵

---

## 🎨 Customization
All colors live at the **very top** inside the `:root` block. Change anything in seconds:

```css
:root {
    --accent: #5ac8fa;     /* Main blue glow */
    --overlay: rgba(5, 12, 25, 0.7);  /* Darken/lighten background */
    /* ...and more — all grouped together! */
}
